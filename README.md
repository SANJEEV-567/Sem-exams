## 🚀 Key Features of the Exam Portal

1. **Two Specialized Practice Modes**:
   - **Exam Mode**: Strict 2-hour university exam simulation with live countdown clock (`02:00:00`), color-coded urgency alerts (Amber $\le 30$ min, Red pulsing $\le 5$ min), auto-submission on timeout, and hidden solutions until submission.
   - **Practice / Study Mode**: Instant step-by-step solution drawer with trap explanations available after selecting any question.
2. **Interactive 160-Question Navigation Palette**:
   - 🟢 **Answered**
   - 🔴 **Not Answered**
   - 🟣 **Marked for Review**
   - 🔵 **Answered & Marked for Review**
   - ⚪ **Not Visited**
   - Filterable by Topic (Topics 2–8 + Bonus).
3. **KaTeX High-Quality Mathematical Rendering**:
   - Clean rendering of partial derivative symbols ($\frac{\partial u}{\partial x}$), determinants, Jacobians, fractions, integrals, powers, and trigonometric functions.
4. **Comprehensive Results & Analytics Dashboard**:
   - Final scaled score out of **40.0 Marks**.
   - Raw correct count out of **160**.
   - Accuracy rate and pacing analysis.
   - **Topic-wise performance breakdown table** with visual proficiency bars.
   - Full question-by-question review with filter chips (`All`, `Correct`, `Incorrect`, `Unattempted`).
   - Step-by-step mathematical proofs and explanation of distractors and trap options.
5. **Local Storage Auto-Save**:
   - Automatically preserves your selected answers, visited questions, review marks, and timer progress on page reload.
6. **Built-in Scientific Calculator**:
   - Floating pop-up calculator supporting trigonometric, logarithmic, square root, power, and algebraic functions.
7. **Dark Mode / Light Mode**:
   - High-contrast night theme and clean daytime theme.
8. **Print & PDF Export**:
   - Clean printable report layout for offline study and revision.

## 💻 How to Launch the Exam Portal

Open `index.html` directly in any modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Brave, Safari):
- **Option 1**: Double-click `index.html` in your file explorer.
- **Option 2**: From the terminal in this directory:
  ```powershell
  start index.html
  ```
- **Option 3**: Using any local HTTP server:
  ```powershell
  npx serve .
  ```
